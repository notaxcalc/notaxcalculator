# Changelog

All formula and methodology changes are documented here.

## v2.0 - 2026 methodology documentation update

### Updated

- Reworked documentation for the 2026 calculator methodology.
- Added Head of Household support.
- Updated 2026 federal tax brackets and standard-deduction presets.
- Documented the $12,500 individual and $25,000 Married Filing Jointly deduction limits.
- Documented the $150,000 and $300,000 phaseout thresholds.
- Documented the $100-per-$1,000 phaseout model.
- Added explicit qualified-overtime terminology.
- Clarified that the full overtime paycheck is not treated as tax-free.
- Added 2026 W-2 Box 12 Code TT documentation.
- Added MAGI estimation limitations.
- Added federal-only scope.
- Added higher-multiplier handling notes.
- Added explicit calculator limitations.
- Added worked examples.
- Added a clear distinction between estimation and official tax-return reporting.

### Removed or corrected

- Removed the "formula-driven, not estimated" claim.
- Removed the separate tips-deduction calculation from the overtime calculator methodology.
- Removed unsupported claims that the calculator produces an exact IRS result.
- Removed outdated 2025-only bracket documentation from the current methodology.
- Removed unsupported claims that every type of overtime premium qualifies.
- Removed language suggesting the entire overtime paycheck is tax-free.
- Removed the obsolete "pending IRS guidance" wording for 2026 W-2 Code TT reporting.

## v1.1 - July 2025

### Added

- Tips deduction calculation as a separate, additive deduction.
- Tips deduction cap: $12,500 (single) / $25,000 (MFJ).
- Tips and overtime savings displayed independently in the output.

## v1.0 - July 2025

### Added

- Initial release.
- OBBBA overtime premium deduction formula.
- Single and Married Filing Jointly filing statuses.
- Phaseout reduction: $100 per $1,000 of MAGI above threshold.
- Deduction cap: $12,500 (single) / $25,000 (MFJ).
- 2025 federal income-tax bracket lookup.
- Standard deduction applied before bracket lookup.
